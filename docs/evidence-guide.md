# Evidence guide

Add a source to the workbook before referencing it from an entity,
relationship, name, location, or platform participation.

Prefer:

1. official agency or laboratory webpages;
2. government directories and organizational charts;
3. official program, technical, or governance documents;
4. maintained registries or directories;
5. secondary sources only when an authoritative source is unavailable.

For each source, capture a useful title, publisher, URL or document identifier,
retrieval date, and a precise locator such as a page, section, table, or
heading. Use the notes field for short curation context, not for copied
documents or sensitive information.

Refer to sources from other workbook sheets using semicolon-separated temporary
keys, for example `SRC-001; SRC-004`.

Conflicting sources should be preserved rather than silently overwritten. Keep
the affected assertion provisional or disputed and explain the conflict in the
notes field until it can be reviewed.
